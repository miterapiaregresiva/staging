# staging — laboratorio beta

Este repositorio se usa como laboratorio de producto para componentes beta de miterapiaregresiva.com antes de integrarlos en `stg`.

## Prototipo actual
Biblioteca por autores:
- estantes por autor;
- scroll horizontal;
- tres densidades de portada;
- vista de biblioteca de autor;
- vista de libro con solapa del autor;
- acceso a Internet Archive y BICA;
- ampliación de carátula;
- responsive móvil / escritorio;
- soporte de `prefers-reduced-motion`.

## Indexación
Este entorno está deliberadamente bloqueado para buscadores mediante:
- `meta robots`;
- `robots.txt`;
- `X-Robots-Tag` en `_headers`.

No contiene todavía las carátulas ni biografías definitivas.
